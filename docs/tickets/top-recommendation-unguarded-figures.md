## Options

- Run the same figure guard on the top recommendation, against the same
  payload, with one retry of the plan call; on a second failure, fail the
  whole review visibly (the letter and the recommendation are saved together).
- Or derive the recommendation's figure in code (the coaching layer already
  computes `startingContribution` and `rankedNeeds`) and let the model only
  phrase it.
